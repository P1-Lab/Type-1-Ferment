# Interfaces Definition

## Electrical Interfaces

- Input: 220V AC, IEC 60309 industrial connector
- Internal distribution:
  - 24V DC logic systems
  - 220V AC heating systems

---

## Sensor Interfaces

- Temperature sensors (high precision, ±0.1°C Chamber A, ±0.2°C Chamber B)
- Relative humidity sensors (±2% accuracy)
- Gas composition sensors (CO₂/O₂ monitoring optional)

---

## Actuator Interfaces

- Variable-speed airflow fans
- Heating elements per chamber
- Solenoid valves for gas exchange
- Ultrasonic humidity generator
- UVC sterilization emitters

---

## Mechanical Interfaces

- Tray system: 40 × 60 cm perforated trays
- Modular rack system for Chamber B
- Stackable chassis design (dual-unit compatible)
- Service-access panels for maintenance

---

## Software Interfaces

- Embedded firmware control system
- PID parameter tuning interface
- CSV data export via network interface
- Real-time sensor monitoring stream
